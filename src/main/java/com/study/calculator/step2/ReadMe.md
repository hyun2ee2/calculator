# 내일배움캠프 계산기 과제 ReadME

---

안녕하세요 내일배움부트캠프 Spring3기 수강생 홍성현 입니다.
이번 과제는 두개의 STEP으로 구성된 계산기 프로그램 구현 과제로, STEP1에서는 사칙연산 기능을 갖춘 계산기를구현하고,
STEP2에서는 STEP1에서 구현한 계산기를 객체지향적으로 개선하여 클래스를 분리하고 각 클래스의 역할을 명확히 나누는 것을 목표로 하여
작성하였습니다.

---

## 주요 기능

- 처음 사용자로 부터 두개의 값과 연산자를 입력 받은 후 계산을 진행
- 계산 결과를 저장하고 이전 계산 결과를 조회할 수 있음
- 소수점 계산을 지원하며, 정수 결과는 불필요한 ".0"을 제거하여 출력

---

## 프로젝트 확장성

문제에서 요구하지는 않았지만, 사용자의 편의성을 고려하여 곱셈 연산 시 "*" 뿐만 아니라 "X" 또는 "x" 입력도 인식할 수 있도록 구현하였습니다.
또한 소수점 계산이 가능하도록 기능을 확장하였으며, 이전 계산 결과를 출력할 때에는 소수 값은 Double 형태로, 정수 값은 불필요한 .0을 제거하여
int 형태로 출력되도록 처리하였습니다.

---

## 프로젝트를 통해 배운점

- 계산 로직과 입출력 로직을 분리함으로써 각 클래스의 역할을 명확히 하는 객체지향 설계의 중요성을 이해하게 되었습니다.
- 컬렉션(List)를 활용하여 계산 결과를 저장하고, 캡슐화를 통해 간접적으로 접근하는 방법을 배웠습니다.
- Double타입으로 계산 결과를 저장하되, 출력 시에는 정수와 소수를 구분하여 사용자에게 더 가독성이 좋은 결과를 제공하는 방법을 배웠습니다.
